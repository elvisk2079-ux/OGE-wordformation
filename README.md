# OGE-wordformation

Интерактивная страница **Word Formation ОГЭ**: 75 текстов из открытого банка заданий ОГЭ ФИПИ (словообразование), все на одной странице, с проверкой ответов и автосохранением в браузере.

Формат — как в [Grammar Task ОГЭ](https://elvisk2079-ux.github.io/OGE-grammar/grammar-task/) (слово заглавными буквами справа, пропуск в тексте), но в синей цветовой гамме — чтобы отличать от грамматики.

Опубликовано через GitHub Pages: https://elvisk2079-ux.github.io/OGE-wordformation/
